# Types that hold a reusable credential and must never derive `Debug`
# (WOR-2640). One entry per line:
#
#   <path> | <Type> | <test fn that pins it>
#
# `scripts/check-secret-debug-registry.sh` refuses a tree where any
# entry has regained `Debug` in its derive, lost its hand-written
# `impl std::fmt::Debug`, or lost the test that pushes a sentinel
# through it. There are no exemptions and there is no baseline count:
# every line here names a type somebody already decided a `{:?}` must
# not print, so a line going red means that decision was reversed.
#
# This list is append-only in practice. Removing a line is removing a
# protection, and the only honest reason to do it is that the type
# itself is gone.
#
# What this cannot see, said plainly because a guard trusted past its
# detector is worse than none: a *new* secret-bearing type that never
# gets a line here. Nothing derives the list from the code, because
# "this field holds a credential" is a judgment about meaning and not
# a pattern. Adding the line is part of adding the type.
